# Jiahui Zhao Personal Homepage

This is a simple static personal homepage for GitHub Pages.

## How to use

1. Create a GitHub repository named `your-username.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Go to **Settings → Pages**.
4. Set **Source** to `Deploy from a branch` and choose the `main` branch.
5. Your homepage will be available at `https://your-username.github.io/`.

## Files

- `index.html`: homepage content
- `style.css`: page styling
